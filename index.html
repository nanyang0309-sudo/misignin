v1.1.3：把自查单里“不花钱就能修”的这批补上

上一轮安全自查列了 11 条问题，这版先把零成本、纯代码能解决的那批全部改掉——重定向、官网白名单、强制更新、剪贴板、退化存储、防截屏、残留包清理，一个版本打包解决。

  • 更新下载不再自动跟随 302，每一跳都重新校验域名白名单，跳到别处立刻中止
  • 公告栏官网地址加域名白名单，只能落到我这边的域名，无法被指向钓鱼站
  • 连续 3 次连不上公告页会要求先解决网络；「稍后更新」改用开机时长计时，改系统时间无效
  • 剪贴板不再自动导入，每次都弹窗问你，点「导入」才写盘
  • 删掉可逆混淆的降级存储：Keystore 用不了就不保存，不留能还原的凭据
  • 签到页加防截屏；启动时清理历史更新包
  • 签名密钥迁到独立目录，口令只存系统环境变量，磁盘上不再有口令文件

上一版：v1.1.2 公告栏文案改成“连公告页自动更新”

以前首页那张公告栏卡片上的字是写死在安装包里的，改一句就要重新打包、重新发一遍。这版把标题和说明改成启动时从公告页读，我改一行字，你下次打开 App 就变，版本号不用动。

  • 公告栏标题 / 说明 / 官网地址改由公告页下发，改公告不用重新发版
  • 这段文案单独用 sig2 验签：页面被人改过就不采用，自动回退 App 内置文案
  • 官网地址只接受 https，而且必须验签通过才会显示和跳转
  • 老版本（v1.1.1 及更早）只认 sig，照常能收到这次更新提示

上一版：v1.1.1 把更新链路做成“全程验签”

上一版的安全自查发现：配置和安装包都没校验，谁改了公告页就能把任意 App 推给用户装。这版直接把两道门都上了锁——公告配置带 RSA 签名，安装包下载后核对签名证书、包名、版本号，任何一项对不上就当场拒装。

  • 公告配置签名校验：页面被人改过，App 直接忽略这次更新
  • 安装包验签：证书指纹 + 包名 + versionCode 三项全对才交给安装器
  • 下载地址只认 https + 自家分发域，换个域名就拒下
  • 安装改走 PackageInstaller 会话 / 显式系统安装器，第三方 App 接不走
  • 强制更新加了「稍后再说（24 小时）」，连续失败 3 次自动放行
  • 剪贴板自动导入默认关闭；下载限 20MB、文件名净化、装完清旧包

上一版：v1.1.0 首页常驻「公告栏」

App 首页标题下面多了一张常驻的公告栏卡片：里面写着官网地址（点是就复制），下面两个按钮「打开官网」「更新公告」。它不折叠、不弹一次就消失，每次打开 App 都在那儿。

红米 K80 上点更新会「下载失败」，装的时候还会弹「解析软件包时出现问题（11）· no filename found」。原因不在包，而在更新方式：旧版把下载交给系统下载管理器，HyperOS 会把它掐掉；装的时候又只给系统一个没有文件名的地址。

  • 更新包改由 App 自己 HTTP 直连下载，不再依赖系统下载管理器
  • 新增自带 FileProvider，按 MiSignIn-v1.0.4.apk 这个规范文件名交给安装器，名字不会再丢
  • 下载有进度日志，坏包 / 半截包会被识别并重下
  • 缺「安装未知应用」权限时，App 直接带你去那个开关，回来一点就装上

它能做什么

少点几下，少绕几圈
⚡

一键签到

点「开始签到」，App 直接调官方接口完成签到，并把结果写进运行日志，签到天数、状态一眼可见。

🧭

人机校验不迷路

遇到 640 人机校验失败 时，自动跳到小米社区 App 的「签到」页，不用再自己找首页左上角那个小图标。

🔐

双登录态，本地加密

同时支持微信小程序和 App 两套登录态，读取后加密保存在本机（AES-GCM + Keystore），不写进安装包、不上传。

🧩

液态玻璃界面

状态卡、双抓取按钮、运行日志都做了玻璃质感，日志自动滚到底、也能手动往回翻。

📣

强制更新 + 公告

启动自动检查版本：有新版本就弹公告、锁定界面，写明这次修了什么加了什么，一处下载直达。

📦

下载就是 APK

更新由 App 自己 HTTP 直连下载、自带 FileProvider 交给安装器，文件名固定成 MiSignIn-v1.0.x.apk，不再出现乱码名和「no filename found」。

先说清楚

这工具能用，但别乱用

使用须知

  • 需要 root：抓登录态是直接读微信 / 小米社区 App 的本地存储，没有 root 抓不到。
  • 只给你的账号用：这是个人签到小工具，不做批量签到、不做多账号刷量。
  • 人机校验必须你本人过：App 只负责把你送到官方签到页，验证码不代点、不破解、不接打码平台。
  • 登录态只在本机：加密存在本机，不上传、不进安装包；过期了重新抓一次即可。
  • 官方接口会变：签到逻辑依赖官方接口，接口调整时可能失效，等版本更新修。
